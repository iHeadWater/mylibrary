# 公共模板

团队维护一套公共模板，不按学生或证据包复制多套。

- [evidence-cards/](evidence-cards/README.md)：八类 Markdown 粗卡模板；_catalog.json 保存来源提交、本地版本及内容指纹。
- [themes/](themes/README.md)：已启用的统一主题规划、定向精读、回填模板和传输 schema，不再只是预留目录。

模板指导“分析哪些内容”；[automation/prompts/](../automation/prompts/README.md) 指导“如何阅读和执行”；Python 管理身份、流程及安全保存。模板中的详细写作要求不是正文标题/措辞的硬性验收门槛。

修改证据模板需同步版本和清单指纹。修改主题模板会产生新的输入版本，但不会另建独立主题池或自动重做全部旧精读；旧粗卡也不因模板升级自动覆盖。
