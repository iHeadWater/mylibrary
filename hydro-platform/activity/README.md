# 关键贡献事件

本目录保存适合团队共享的关键事件，用于帮助老师掌握流程进度和发现阻塞。

2026-09-09 已实现 ledger.json 基线与去重账本，run-once 自动维护；也可运行 `python automation/run.py activity-sync --json`。首次启用不回放历史贡献。不要把此账本放进可丢弃的运行缓存或手工改哈希。[事件语义、恢复和身份限制](../documentation/activities-and-daily-report.md)。

第一版关注：

- 成员新增 Zotero 论文父条目；
- 成员给已有条目补充 PDF；
- 系统成功创建或更新证据包；
- 系统发现缺少 PDF、PDF 不可读或制卡失败。

同一论文可以有多位贡献者，每种行为分别记录。事件不得用于学生排名或绩效评分，也不得包含原始运行日志和密钥。

ledger.json 是共享成果，不属于可丢弃的运行缓存。贡献者只能来自本机 API 明确返回的身份，再用 members 中的映射转换；未知身份不能猜测。账本由程序维护，日常阅读[老师摘要](../reports/daily/README.md)，不手工改账本或内容指纹。
