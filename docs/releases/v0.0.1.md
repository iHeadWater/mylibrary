# mylibrary v0.0.1

首次 GitHub Release（2026-10-12），提供当前主线的可追溯代码快照与使用说明。版本由 uv 管理；
本次不上传 PyPI，也不附加 wheel/sdist。以下是本版包含的已有能力，不表示它们都在本次发布准备中新增。

## 本版提供

- **论文入库与读库**：支持论文下载与 Zotero 入库流程，以及通过 MCP 工具搜索、读取文献和附件。
- **文献卡与候选主题**：从自己的 Zotero 论文生成主体卡草稿，进行确定性校验，再组织候选主题；
  模型 CLI 适配器支持 Claude 与 Codex，实际模型由对应 CLI 的配置决定。
- **文献深度处理**：保留精读、公众号、NotebookLM 简报与播客等工具入口；各项能力的账号和依赖按需配置。
- **在线文档**：[Hydro AI Papers](https://iheadwater.github.io/mylibrary/) 提供安装、用户指南、模板与开发说明；
  文档修改进入主线后自动发布。
- **版本维护**：用 uv 更新版本与锁文件；新增 GitHub Actions 发布检查，核对版本、测试、命令入口、离线示例和文档构建。

## 使用这个版本

在 PowerShell 中执行：

```powershell
git clone --branch v0.0.1 https://github.com/iHeadWater/mylibrary.git mylibrary
Set-Location mylibrary
uv sync --locked
uv run hydrolitagent cards --help
```

检出 tag 后处于固定版本快照；如需开发，请另建分支。Python 要求为 3.12–3.14。
文献卡与主题卡运行时目前为 Windows-only。真实论文流程还需要 Zotero Desktop、可读 PDF、
已登录的 Claude/Codex CLI 及 Poppler；不需要照抄作者的本机路径或模型账号。
完整前提见[安装配置](https://iheadwater.github.io/mylibrary/getting-started/installation/)。

## 验收与边界

- 发布前运行完整现有测试套件、CLI 帮助入口、合成示例的离线校验和 MkDocs 严格构建，
  并等待主线与 tag 的 Release checks 成功。具体计数和跳过原因见对应 Actions 日志。
- 本机完整套件结果：**872 passed、16 skipped、164 subtests passed**。
  其中 15 项因 Zotero Desktop 本地 API 不可达而跳过，另 1 项公开演示论文集成测试未启用。
  没有通过排除失败用例来取得这一结果；离线校验返回 `PASS`，严格文档构建通过。
- 本次发布验收不新增调用付费模型，也不重新验证每一种出版商下载、公众号发布或 NotebookLM 外部服务。
- 离线示例通过只说明代码校验入口可用；卡片通过确定性校验，不等于科研结论已核实。
- 正式主题仍需人工决定，专用确认命令尚未实现；idea 生成和平台受控接入 Obsidian 尚未作为当前运行命令提供。
- 当前主题处理面向小样本文献库，大规模上下文检索与压缩尚未实现。
- 运行产物与凭据不提交到 Git；许可证为 AGPL-3.0。

## 后续维护

后续版本先确定目标与验收条件，再按变化选择 patch / minor / major。
版本号、tag 与 Release 保持一致；通过新的版本发布修正，不移动已公开的 tag。
