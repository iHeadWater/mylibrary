# 单 Agent、模板驱动、详细粗卡

当前采用单 Agent 制卡：`evidence-generate` 用一次模型调用生成一张详细粗卡，替代早期六角色方案，不追改历史结果。模板是 AI 写作指引，不是保存合约；程序仅检查流程，不校验正文格式或内容质量。

## 目的与范围

用户没有逐卡科研复核的人力；粗卡供后续主题处理使用。“粗”仅表示未围绕某个主题定向深化，不表示只读摘要或省略重要细节。本页止于单篇卡片生成；候选主题与正式主题由[统一主题池](../../user-guide/cards/unified-theme-pool.md)和[科研工作流](../../research-workflow/index.md)处理。

## 当前流程

Python 核对输入记录、原 PDF 和模板索引 → 一个模型独立会话读取文字及页面图像、自动选型、按模板详细写作 → Python 检查来源、执行完成、非空结果、重复/覆盖及写入状态 → 保存 `card.md`、`draft.json` 与草稿记录。

- 只有一次提供者 generate 调用；CLI 在本次会话内可能调用多次本机工具或自行重连，不是承诺一个网络请求。
- 不要求摘句、逐字匹配、固定事实数、批判条数或人工审批；不派生子 Agent。
- 使用九类证据卡模板；当前平台目录版本为 2.0.1，正文骨架基于 V1.7，详见[公共模板](../../user-guide/cards/templates.md)。
- 模型、强度和超时来自总配置或 `configs/ai.toml`；一个会话使用 `generation_timeout_seconds`，不再使用六个角色各自的配置。

## 内容及验收边界

| 层次 | 给 AI 的写作要求 | 程序保存时的处理 |
| --- | --- | --- |
| 原文陈述 | 作者报告的结果、解释、假设和建议，区分其性质 | 原样保存，不检查编号、标签或列数 |
| 原文转述 | 当前论文引用的他人研究；不冒充已读被引原文 | 原样保存，不声称机器已确认归因 |
| AI 推理 | 说清依据、推导、额外假设、适用条件和边界 | 不要求固定章节名或标签 |
| 信息边界 | 客观说明缺失及影响 | 作为写作指引，不用正则扫描措辞作为门禁 |

模板仍要求详细说明研究问题、数据、尺度、方法链、结果、图表和局限，并区分事实与推理。但标题、顺序、列数、数量、标签、编号、占位词和措辞既不拦截，也不额外做一轮机器内容检查或自动返工。可信身份和状态始终由 Python 从输入上下文写入，不用模型正文覆盖。

保留硬检查：来源身份与 PDF 指纹正确、PDF 读取执行/报告满足既有流程、模型调用正常完成、交付 JSON 能被程序处理、模板 ID 指向已启用模板、Markdown 为非空文本、不覆盖以及多文件保存完整性。模板 ID 只是运行记录索引，不校验其正文匹配度。

## 操作

单篇生成通过 `evidence-generate` 完成，完整命令与返回值见[单篇论文命令行流程](../../user-guide/cards/single-paper-quickstart.md)与[主体卡草稿](../../user-guide/cards/subject-card-draft.md)。生成的草稿一律为待校验状态，须经 `evidence-validate` 通过后才能进入主题流程。

## 输出保全与故障

- 模型返回的最后一条消息先保存在 `paths.runtime_dir` 下的草稿文件，标为未校验输出，不是正式卡、不供主题读取。
- 保存位置由运行目录派生；不记录原始命令输出或认证信息。它含未校验模型内容，仅留本机，不提交 Git。
- 临时目录清理失败只警告，不把成功调用判成模型失败、不重跑模型。
- 真正的进程/文件错误保留发生阶段、异常类型与错误码；输出校验失败尽可能附上草稿路径。

## 当前配置与兼容

总入口仍为 `hydrolitagent/cards/assets/config/config.json`（单篇也可用 `configs/ai.toml`）。`workflow_mode=single_agent`，`pdf_reader.adapter=local_path`；单 Agent 模式不能同时提供 `multi_agent_workflow`，避免无效角色覆盖值误导。Python 环境是 仓库根 `.venv`（`uv sync --all-packages` 准备）。

主提示词为 `evidence-card-generation-v8.md`，共用读取指引为 `pdf-local-reading-v1.md`。v8 将详细写作要求与保存条件分开，不降低全文阅读范围，不增加模型复核或格式修复调用。读取解释器、shell、沙箱、文字引擎仍放在 `card_generator.pdf_direct_trial` 对象中，与正式路径读取共用。

## 验证

单 Agent 的来源身份、模板路由、幂等和安全写入由自动测试覆盖。当前命令、最新结果与未验证边界统一见[验证地图](tests.md)。
