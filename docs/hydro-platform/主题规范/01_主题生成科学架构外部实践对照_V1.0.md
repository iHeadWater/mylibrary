# 主题生成科学架构外部实践对照 V1.0

形成日期：2026-09-07
性质：主题 Skill 的设计依据；不替代具体学科判断、正式系统综述方案或导师决定。

## 1. 本次要解决的问题

课题组需要从多张证据卡形成可以继续用于文献综述、研究问题、Idea和学术写作的主题，同时用主题反推哪些论文最关键、哪些原卡必须补核。用户明确要求新论文和高影响因子论文在排序中获得更高影响，但整个系统不能捏造、不能把期刊指标当成论文结论的正确性。

## 2. 会议记录中的老师意见

会议转写仅作为内部设计依据，不能当作逐字准确的科研来源。对能够明确识别的意见作以下保守归纳：

- 00:15:42—00:18:13：证据卡的价值应服务于把握主题、筛选前沿、梳理行业发展脉络和研究现状，并进一步寻找选题；“冲突”只有在同一区域或同一问题等可比条件下才成立，不同对象的差异不能强称冲突。
- 00:23:22—00:25:50：Idea来自文献与研究者认知的结合，自动化难以量化研究者的“taste”，必须保留人机交互。
- 00:30:11—00:34:16：文献库只是资源入口；证据卡把单篇来源结构化，多张卡再形成主题；需要划清确定性流程、AI可做事项和必须由人判断的事项。
- 00:29:12—00:30:11：团队需要统一文献入口、查重和共享知识上下文，Zotero、Obsidian与操作平台承担不同职责。

因此，本项目的主题输出不是关键词聚类或冲突清单，而是“发展脉络—研究现状—证据边界—前沿优先级—待补核—写作接口”的主题档案。

## 3. 外部事实

### 3.1 DORA：期刊指标不能替代单篇研究质量

[San Francisco Declaration on Research Assessment](https://sfdora.org/read/)明确反对把 Journal Impact Factor 等期刊层面指标作为单篇文章质量的替代量。DORA还指出期刊内引用分布偏斜、不同学科和文章类型混合等局限。

### 3.2 Leiden Manifesto：定量指标应支持专家判断并考虑学科差异

[Leiden Manifesto](https://www.leidenmanifesto.org/)提出十项研究评价原则，其中包括定量评价支持定性专家判断、考虑不同领域的发表与引用习惯、过程和数据应透明可核。它讨论的是研究评价，不直接提供主题生成算法。

### 3.3 Cochrane：综合应按问题、可比性和确定性评价

[Cochrane Handbook第14章](https://training.cochrane.org/handbook/current/chapter-14)对一组证据的确定性使用风险偏倚、不一致性、间接性、不精确和发表偏倚等维度；这些维度围绕具体结局和问题判断，不使用期刊影响因子代替证据质量。

[Cochrane Handbook第15章](https://training.cochrane.org/handbook/current/chapter-15)要求讨论主要结果、证据完整性和适用性、确定性、与其他研究的一致或不一致，并强调目标情境与研究情境之间的适用差距。

[Cochrane Handbook第4章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04)区分“研究”与同一研究的多个报告，要求处理重复报告、检索和选择过程，并建议更新检索以保持当前性。

[Cochrane Handbook更新章节](https://training.cochrane.org/handbook/current/chapter-iv)指出新增比较或结局时，可能需要回到原纳入研究检查以前未提取的信息。这为“主题发现缺口后回到原卡补核”提供了可借鉴的闭环原则。

### 3.4 PRISMA：选择和综合过程需要透明报告

[PRISMA 2020](https://www.prisma-statement.org/prisma-2020)提供系统综述报告清单和流程图，要求报告为何开展、用了什么方法和得到什么结果。PRISMA是报告规范，不是单篇证据质量评分工具，也不能证明主题结论正确。

## 4. 可借鉴原则

1. 主题综合先定义问题和范围，再选择、比较和解释证据。
2. 证据确定性与期刊影响指标分开。
3. 同一研究的多篇报告、共享数据和版本不能重复计数。
4. “冲突”要先检验研究对象、比较口径和情境是否一致。
5. 综合要同时呈现直接证据、限制、负结果、适用性和未知。
6. 更新不是简单加入新文献；新增问题可能要求回看旧来源并补取此前未记录的信息。
7. 定量排序必须公开公式、输入、缺失和适用范围，并由专家判断校正。

## 5. Codex推断

以下是根据课题组目标与上述实践作出的工程推断，不是外部标准原文：

- 把主题拆成 Scope、Manifest、Comparison Frame、Synthesis Statement、Priority、Feedback、Writing Readiness 和 Review 八个可审计部分；
- 用已核 Claim ID 作为主题事实接口，避免重新抄写一套来源事实；
- 将文献重要性分成“科学作用”和“前沿关注优先级”两个轴；
- 只有在同一 comparison frame 内，才允许记录真正冲突；
- 主题反馈只生成原卡补核请求，实际改变必须回到原来源和原卡；
- 主题一旦因补核发生承重变化，必须重算相关综合和排序；
- 当前证据集合中的空白只产生 opportunity signal，不能直接变成新颖性声明或正式Idea。

## 6. 本项目选择

### 6.1 前沿关注评分

为了落实用户对新论文和高影响因子论文的偏好，前沿关注分采用：

- 证据质量与独立性25%；
- 问题直接性20%；
- 缺口闭合价值15%；
- 新近性25%；
- 经核的学科归一期刊信号15%。

新近性与期刊信号合计40%，因此会显著提高近期高影响期刊论文的阅读和更新优先级。

### 6.2 指标边界

- 该分数只排“下一步先看谁”，不进入Claim核验状态和主题证据确定性；
- 期刊信号优先用同年度、同学科的JIF百分位，分区只能降级使用；原始JIF不能跨领域直接比较；
- 所有指标必须带来源、年份、学科、百分位／分区和核查日期；
- 指标未知就给分数区间，不能填0或猜测；
- 非期刊来源将期刊分项标为不适用并重归一权重；
- 奠基研究、定义、长期监测和历史基线可通过明确的 foundational exception 保留；
- 任何高分都不能越过L2/L3与source-checked准入门。

### 6.3 人机权限

生成器只预填确定性元数据、声明准入账和快照；AI提出主题结构、综合草稿、排序输入和反馈请求；人工复核承重声明、可比性、边界和指标；导师或授权者决定正式主题的建立、激活、拆分、合并、改名和归档。

## 7. 没有照搬的部分

本平台不是正式系统综述工具，不声称完整执行Cochrane、GRADE或PRISMA。水利研究包含观测、模拟、工程、标准、数据和软件等多类证据，不能套用单一临床证据层级。外部实践只用于约束透明性、可比性、更新和指标使用，具体主题判断仍以水利对象、方法和原文为准。
