**描述：**作为自动化维护者，我希望后台命令能够在没有 Codex 对话窗口的情况下检查 Zotero 和目标共享库，以便后续任务有稳定入口。

**验收标准：**

6. 从仓库以外的工作目录执行时，路径仍相对于总配置所声明的项目根目录解析。

**状态：**历史技术基线。真实 PDF 已成功跑通并生成 `ROUGH` 卡，但用户判断卡片质量一般，不能算产品验收通过；正式流程由 US-07B4 取代。底层 Codex CLI/PDF MCP/安全写入能力继续复用。

**验收标准：**

1. Python 程序通过非交互 Codex CLI 发起制卡，不需要打开 Codex 对话窗口或由人工发送消息，并且必须先通过 US-07A 和 US-07B1；
2. 一次调用只处理一篇论文；Python 把 US-06 校验后的 PDF 路径、父条目 Key 和 SHA-256 绑定给项目内置只读 MCP。Codex 必须调用唯一的 `read_full_source_pdf`；该工具在一次调用内部按配置批次从第 1 页读到最后一页，并交付每页文字和页面图像，不能依赖模型自行循环；只读题名、摘要、元数据或索引全文不算完成；
3. 只有证据包中的 card.md 仍为 `PLACEHOLDER` 且输入指纹与 manifest.json 一致时，系统才调用 AI；
4. card.md 已包含粗证据卡或其他非占位内容时直接跳过，不调用 AI，也不改写已有卡片；

7. Codex 在一次模型调用中完成唯一模板分类和粗卡正文生成，但无权直接写仓库；Python 确定性写入身份与版本字段，校验后再替换占位卡；
8. 模型必须返回实际页数、全文阅读状态、视觉内容检查状态和可追溯阅读回执；PDF 有图、表或需要视觉理解的公式但无法检查时不得写卡。至少用一篇需要跨页和图表取证的样本验证模型不是只依据标题、摘要、首页或纯文本作答；
9. 原文缺失的信息只能写“原文未报告”“当前 PDF 无法确认”或“不适用”，不得猜测，也不得残留模板占位符。

## US-07B4：历史六角色方案（已被单 Agent 取代）

2026-09-08 用户决定：默认单 Agent、模板驱动、详细粗卡，取消逐卡人工核验要求。当前实现和验收见 [单 Agent 规则](single-agent-rough-card.md)。以下条目保留历史设计，不再作为当前默认验收标准。

**状态：**代码和 136 项全量自动化测试通过；尚未替用户运行真实论文。当前仅实现 `codex_cli` 提供者，但六角色编排与提供者调用已分层。

**描述：**作为导师，我希望任何 AI 都必须通过程序规定的独立事实提取、裁决、批判分析和对抗复核后才能写入粗卡，以便即使更换模型，也不能只靠提示词承诺“不偷工减料”。

**验收标准：**

1. Python 必须按固定顺序启动 `fact_extractor_a`、`fact_extractor_b`、`fact_adjudicator`、`critical_analyst`、`card_synthesizer`、`adversarial_reviewer` 六个独立临时调用；缺少、合并或跳过任一角色都不允许写卡；
2. A/B 相互不可见，各自从完整 PDF 提取研究问题、数据、方法、结果、视觉证据、局限和负结果，并给出原文页码；
3. 裁决角色必须重新读取原文，把已验证事实映射回 A/B 的事实 ID，解决或显式记录分歧；未解决高风险分歧超过配置阈值时停止；
4. 批判分析只能基于已裁决事实判断证据强弱、因果边界、方法漏洞、外推范围和潜在冲突；
5. 合成角色只能使用裁决事实与批判分析填写一个已启用模板，不得声称完成人工复核，也不得生成主题或 idea；
6. 对抗复核必须在新上下文中挑战事实支持、数值准确、因果语言、作者/平台判断边界和视觉解读，并检查研究问题、数据、方法、结果、视觉、局限和负结果覆盖；任一必修项失败都不返回可写候选卡；
7. 当前 v2 每个角色记录同一 PDF 的哈希、页数、本机预检结果、命令活动和全文/视觉阅读声明；只凭“已阅读”且无任何读取命令不放行，但不伪造独立阅读证明。不要求固定页摘录、逐字匹配或 MCP 回执；
8. Python 必须校验角色集合、顺序、跨角色 ID、证据页码、数量阈值、模板结构和最终裁决，并保存 `quality-audit.json`；只有全部质量门为真时，才原子写入正式卡和 manifest；
9. 运行或网络故障进入 `RETRY_PENDING`；质量门失败进入 `QUALITY_FAILED`，普通流程不自动重试，只有 `--retry-quality-failed` 显式授权才可重跑；
10. 已有非占位卡不得覆盖；`evidence-generate-trial` 允许对其执行完整六角色试运行，但结果只能写 `.runtime/card-trials/`，不得修改正式证据包和任务；
