# 证据卡填写与原文忠实性规范 V0.3

2026-09-03｜产品候选规范｜适用于[证据卡模板](../证据卡规范/02_原创研究论文证据卡模板_V0.3.md)。本次只定义工作方法，没有真实论文的提取结果或科研质量验收成绩。

## 1. 先约定“丰富”和“忠实”

丰富指足以让人重建作者的问题、设计、比较和结论边界，并能返回原文核对。不能用常识补齐论文没有报告的细节，也不能为填满表格推测参数、样本量、机制或局限。不同论文启用不同模块；不适用的模块写理由后折叠，不把空表数量当完成度。

默认模式是**原文事实与忠实释义**。作者提出的解释仍写“作者解释/认为”；论文引用的前人成果仍写“本文转述某研究”，不冒充已核验一手证据。本方提出的问题进入“待核验”，不混进论文发现。用户另行要求批判性评价时，才新增显式标注的分析段，并逐项列依据与推断距离。

这份卡是同一文献的持续更新记录。一个研究有预印本、正式版、勘误或补充材料时，分别登记来源版本并解释关系；不把它们算成数项独立研究。不把摘要卡、精读卡和主题摘录各自发展为三份不一致的正式事实。

## 2. 字段启用矩阵

| 类别 | 应包含什么 | 完成要求 |
| --- | --- | --- |
| 所有论文的必需核心 | 身份/版本、实际阅读范围、研究问题、对象尺度、作者实际工作、关键证据、作者结论与边界、可返回原文的定位 | 每类有实质内容，或明确说明为什么当前不能判断；摘要不足以验证方法结果时降低可用范围 |
| 实证与模拟研究 | 数据来源和处理、研究设计、对照、指标、主结果、差异或失败、不确定性 | 与主要结论相关的内容必须覆盖；原文不报告的逐项标识 |
| 条件模块 | 水文模型、机器学习、因果研究、优化决策、数据论文、系统综述、理论方法 | 据实际研究类型启用；不能对所有论文强加同一临床或机器学习检查表 |
| 有材料才登记 | 补充文件、勘误、代码、数据、伦理、注册、资助与利益冲突 | “未取得/未检查”与“作者未报告”分开；代码链接存在不等于可运行 |
| 只有真实发生才写 | 下载时间、文件哈希、人工复核、执行环境、运行结果、修改事件 | 不预填完成日期、核对人、通过标记或复现声称 |
| 默认关闭 | 本方创新评分、跨论文结论、机制推断、正式选题/主题升级 | 不能作为忠实摘要自动产物 |

## 3. 每句话属于哪一类

| 类型 | 写法要求 | 允许进入的区域 |
| --- | --- | --- |
| 原文直接报告 | 保留对象、比较、条件与限定；连到具体图表或段落 | 事实、结果、证据登记 |
| 作者解释或推测 | 保留“可能、提示、认为”等认识强度 | 作者解释，不能冒充验证过的机制 |
| 作者自述贡献 | 写“作者声称……”；与本文实际做出的工作对应 | 贡献段，不能自行认证首创 |
| 本文引用他人结论 | 写明是本文转述并登记其引用号；未读一手文献不声称已核验 | 背景及转述证据 |
| 忠实释义或翻译 | 只改表达，不改变数量、方向、范围、否定和不确定性 | 对应事实段；必要时保留术语原文 |
| 本方待核验问题 | 指明问题由哪段证据或哪处缺失引发；疑问不等于缺陷已证实 | 第八部分，不作为作者观点 |
| 本方分析 | 本轮默认不生成；另获任务授权后单列依据、推断与替代解释 | 独立标注的判断区 |

一句包含两项不同来源的事实时拆成 Cxx 声明，或在每个分句标不同定位；不得在长段末放一个引用，让读者误以为整段都有依据。Cxx/Rxx/Uxx 是卡内编号，不是平台正式对象编号。

## 4. 原文定位与核对记录

标准定位组合：`来源 Sxx / 文件或网页版本 / 印刷页码与PDF顺序页 / 节标题 / 图表公式编号 / 可识别的段落或行 / 必要短引文`。PDF只有顺序页时明说；HTML使用标题、段落起始词和表图号，不能编页码。机器提取行号不能替代原版页面定位。

每项影响读者判断的声明，登记以下内容：

| 项目 | 必填含义 |
| --- | --- |
| 声明 Cxx | 一项可被核对的完整命题；避免把结果、解释和建议混成一句 |
| 原文依据 | 足够核实该命题的短摘录、上下文和精准定位；图表结果连到 Rxx |
| 来源角色 | 本文直接证据／作者解释／本文转述／忠实释义 |
| 限定条件 | 人群或流域、时期、尺度、对照、指标、适用范围和否定条件 |
| 核对过程 | 实际看了什么、谁核对、何时核对、发现及处置；未做就写未做 |
| 使用边界 | 可保留的表述、被缩窄的内容和不能用于什么判断 |

逐项核对所有进入卡片的核心科学声明、数值、比较、因果或机制表述、贡献和局限归属。这里的“全部”是过程覆盖目标，**不是零错误保证**。一次复查几句话不能宣布整张卡正确。

不用大段复制论文代替整理。原文短引文服务于核对，全文留在合法来源/Zotero。共享卡片不上传受限 PDF、授权数据库内容、未公开研究材料或凭据。

## 5. 缺失信息必须有精确含义

| 状态 | 使用条件 | 下一步 |
| --- | --- | --- |
| 未读到 | 所需段落或材料尚未阅读 | 记录未读范围，不推断不存在 |
| 原文未报告（限已查范围） | 已检查相关正文、表注等，确实未找到 | 列已查位置；不能声称未查补充材料也没有 |
| 无法取得 | 已知需要某文件，但当前无合法可用访问 | 记录资源标识、尝试和缺口；请求可用材料 |
| 无法辨识 | 扫描、公式、图例或单位无法可靠读取 | 返回原页面核对；仍不清楚则不输出精确值 |
| 不适用 | 研究设计本来不涉及该项 | 写明设计理由，不能掩盖应报告却缺失的信息 |
| 存在冲突 | 摘要、正文、图表或版本给出不一致内容 | 并列保存双方定位，不自行挑更好看的数字 |
| 待核实 | 已有候选解释，但证据尚不足 | 列决定性问题和所需最小材料 |

禁止把“没有找到”写成“没有做”，把“没拿到代码”写成“作者不开源”，把“未报告某项控制”写成“已证明存在偏倚”。

## 6. 数字、方法和统计的高风险检查

1. **数字绑定上下文。** 每个结果至少跟对象、数据分组、时期、指标定义、单位和对照；区分单流域、逐流域平均、样本加权平均、集合统计和总体统计。
2. **原样记录报告方式。** 均值不改中位数；SD、SE、置信区间、预测区间、可信区间不互换；样本数、事件数、站点数、时间步数、模型运行次数分别记录。
3. **保留比较基准。** 优于哪个模型、在哪个样本与指标上，是否同输入、同训练条件和同测试范围。未报告公平性时写未知，不裁决胜负。
4. **不擅自计算派生结果。** 原文没有报告的相对提升、百分比、百分比点差值、效应量、显著性或样本量不生成。若用户另行要求计算，须单列“本方计算”，给原始输入、公式、假设和误差；仍不是作者报告。
5. **不从图猜精确数。** 优先表格与正文；必须读图时注明近似、坐标与方法，不伪造小数精度。图表方向、对数轴、颜色、组别和误差条定义都要检查。
6. **统计显著性不代表实际重要性。** 按原文记录效应和不确定性；不能将未显著写成两者等效，也不能把 p 值写成假设为真的概率。具体原则参考[ASA声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)。
7. **核对验证设计的实际用途。** 论文中 validation 一词可能指调参、早停或最终评估，按操作分别描述；不凭名称认定独立测试。留意时间/空间分割、嵌套调参、预处理拟合范围和预测时输入可得性。没有证据时只能提出待核验问题。
8. **保留关联与因果之别。** 作者使用“相关、提示、可能有助于”时不能升级为“导致、证明、保证”。解释性讨论与实测或干预结果分开。
9. **限制外推。** 特定流域/时期/极端事件下的表现，不自动推广到所有区域、气候、预报时效或工程条件。训练中见过的站点与完全未见站点分开。
10. **保存不利与矛盾证据。** 不能只提最佳结果；作者报告的失效情景、次优指标、异质性与敏感性应进入核心结果或边界，尤其当它们改变结论时。

## 7. 精读与资产检查的停止条件

完整卡片要求核查本文关键设计与证据，不要求不加选择地打开全部附件。追加补读先写清：正在影响哪个判断；缺哪条可定位证据；哪份最小材料可能改变判断。三项不能成立则记录当前边界，不为产出精读记录而补读。

作者声明代码可用、链接实际可访问、环境能安装、程序成功运行、同数据同分析结果得到核对，是不同层级。必须按实际达到的层级登记。阅读论文或运行平台检查不能记成论文实验复现。

## 8. 单人复查的方法与限制

你负责整理，也负责回到原文复查。Codex可以辅助定位、抽取和找矛盾，但生成者的第二次回答不构成独立证据。复查先看源页面，再重建对象—方法—结果—边界，最后与卡片逐项比对；保留错误与修订记录，避免只润色流畅度。

记录分三列：本人原文复查／AI辅助检查／独立人员检查。没有第二位真人时第三列写“未开展”。个人流程可以继续，团队独立验收、独立可理解性或跨设备使用的效果仍不能宣称已验证。

## 9. 术语约定

| 术语 | 本包含义 |
| --- | --- |
| 文献身份 | 一份特定来源及版本的身份，不只是论文简称 |
| 证据卡 | 同一论文的结构化阅读记录，保留八部分正式骨架 |
| 声明 | 卡中一项需要来源支持的命题 |
| 结果 | 原文报告的观察、估计、比较或推导，不自动包含机制解释 |
| 原文忠实 | 范围、方向、数量、条件和认识强度没有被改变 |
| 可追溯 | 能从卡片准确返回支撑内容，不只到论文首页 |
| 已核对 | 明确对象和范围的实际检查动作，不等于论文科学有效性已认证 |
| 可用范围 | 当前材料和核查允许支持的具体判断 |
| 复现 | 指定输入、代码与分析的实际执行及结果核对，不能等同阅读 |
| 未验证 | 当前没有相应证据；不等同失败，也不自动视为通过 |

以上为本轮产品设计选择。外部方法的适用范围与本地正式规则关系见[证据卡架构外部实践对照 V1.2](06_证据卡架构外部实践对照_V1.2.md)。
