# 模板资产

团队维护**一套**模板，不按学生或证据包复制多套。分三组：

| 组 | 在哪 | 谁在用 |
|---|---|---|
| **粗卡模板**（九类，机器生成） | `hydrolitagent/cards/assets/templates/evidence-cards/` | `evidence-generate` / `evidence-validate` |
| **主题池模板**（规划 / 定向精读 / 回填 + schema） | `hydrolitagent/cards/assets/templates/themes/` | `themes-run` |
| **人填的主题模板** | [`主题模板/`](主题模板/00_主题模板使用说明.md) | 人工筛选与正式主题 —— 见第三节 |

`_catalog.json` 记录每个模板的来源提交、本地版本与内容指纹。九类粗卡模板当前**都启用** ——
启用只表示分类器**可以**选它，**不表示**它已通过真实论文的科研质量验收。

## 一、粗卡模板

| 模板 | 用于 |
|---|---|
| `original-research` | 原创研究论文 |
| `review-synthesis` | 综述与证据综合 |
| `survey-monitoring-statistics` | 调查、监测与统计报告 |
| `engineering-report` | 工程项目报告 |
| `book-chapter` | 图书与章节 |
| `standard-guideline-policy` | 标准、指南与政策 |
| `dataset-data-product` | 数据集及数据产品 |
| `software-model-code` | 软件、模型与代码 |
| `platform-decision-synthesis` | 平台证据综合与决策 |

生成时由模型根据完整 PDF **自动选一类**（没有「待人工确认类型」这个状态）。
返回非法或未启用的类别会**直接报错停止** —— 不会静默改用默认模板。

### 与 `skills/hydrology-evidence-cards/` 的关系

那边是**人读证据卡**的骨架（**源**），这边是**机器生成粗卡**用的（**派生**）：
9 个同名文件，正文结构沿用，但这边替换/补充了管线契约所需的 **15 个 front matter 字段**
（证据 ID、Zotero 父条目、PDF 指纹…），由校验器强制要求。

两份**内容不同，且刻意不同步** —— 改源目录**不会**自动同步过来。

### 改模板要守的规矩

1. 升该模板的 `template_version` 和 `_catalog.json` 的 `local_version`，同步更新内容哈希；
2. 引入来源仓库的新版本时，更新来源 commit 与对应的 source blob SHA；
3. **升级不会自动重制历史卡片** —— 历史卡只在后续能力实现后标记「模板版本落后」；
4. 类型纠正或明确触发重制时**生成新版本并保留旧卡**，不能原地覆盖。

## 三、人填的主题模板

上面两节都是**机器**用的；这一组是**人**填的：

| 模板 | 用来做什么 |
|---|---|
| [使用说明](主题模板/00_主题模板使用说明.md) | 怎么用这组模板 |
| [初步主题与人工筛选](主题模板/01_初步主题与人工筛选模板.md) | 把候选主题提炼成「可持续研究的问题」，逐条过筛选门 |
| [既定主题深度综合](主题模板/02_既定主题深度综合模板.md) | 正式主题的万字综合 |
| [主题工作流运行账](主题模板/03_主题工作流运行账模板.md) | 记录一轮工作流的输入、判断与留痕 |

**候选主题不能直接变成正式主题。** 人工筛选至少回答：它是不是一个**可持续研究的问题**
（而不只是方法名、地区名或关键词）？纳入和排除边界能否说明？哪些来源代表该主题、哪些只是相邻或歧义？
它与已有主题是父子、相邻、重叠、合并还是拆分？当前证据是否足以建立，还是该观察 / 补证据 / 拒绝？

决定可以是：建立 / 改名后建立 / 合并 / 拆分后重审 / 观察 / 补证据后再决定 / 拒绝 ——
只有**建立、改名后建立、合并**能产生正式主题，且必须记录**决定人、时间、理由与来源候选**。

正式主题至少包含：核心研究问题、层级与边界、证据来源、Claim 准入、比较框架、当前综合、研究脉络、
异质性与争议、迁移边界、证据缺口、后续补证据任务。**一级**=长期方向；**二级**=相对稳定的问题群；
**三级**只在材料规模和问题边界确有需要时建立。

> 承重内容要用 `skills/hydrology-evidence-cards/` 打开原文、拆成**可定位 Claim**；
> **只有达到 L2 / L3 且完成来源核对的 Claim**，才能支撑正式主题结论。自动化**不做**这一步。

## 边界

- 模板只提供**内容结构**。程序校验模板的**数量 / 来源 / 版本 / 路径 / 哈希**，
  **不检查**正文标题、表格或措辞。
- 主题只**引用**证据包，不复制论文或粗卡。
- 候选主题**不能绕过人工门**；正式主题能回链 Claim 并保留演化历史。
- 科研正确性不由模板或校验保证。
