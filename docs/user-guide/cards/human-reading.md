# 人读那一支：证据卡与正式主题

**自动那一半**（粗卡 → 候选主题 → 代码校验）见[文献卡与主题卡](index.md)。
本页讲**人工那一半** —— 人读证据卡、人工筛选门、正式主题、idea。这些自动化**不做**。

## 五类科研对象

| 对象 | 解决的问题 | 当前情况 |
| --- | --- | --- |
| 来源 | 我们实际读的是哪一份文献或数据产品 | Zotero 与来源版本规则已有 |
| 自动粗卡 | 快速说明一篇来源研究了什么，便于后续发现 | **已实现** —— [从单篇 PDF 生成主体卡草稿](subject-card-draft.md) |
| 科研证据卡 | 哪些 Claim 经过原文定位，可以支持什么结论 | Skill 与模板已有；**未自动接入**粗卡升级 |
| 主题 | 多个 Claim 围绕什么稳定研究问题形成综合 | 候选池已实现（[统一主题池](unified-theme-pool.md)）；正式主题仍需人工闭环 |
| idea 候选 | 哪个缺口可以转为可检验研究问题 | 目标设计，**尚未实现** |

## 从来源到证据卡

一项来源只登记一次准确版本 —— Zotero 元数据用于识别来源，原始 PDF 用于核对科学内容。

**自动粗卡**服务于筛选和候选主题发现：它通过的是来源、流程和保存检查，
**不等于**每个数字、因果解释和图表含义都已由人核验。

当某条认识要进入正式主题或科研决策时，用 `skills/hydrology-evidence-cards/` 工作流打开原文，
把承重内容拆成**可定位 Claim**，并记录推断类型、适用边界、证据来源与人工复核。
**只有达到 L2 / L3 且完成来源核对的 Claim，才能支撑正式主题结论。**

## 从证据卡到主题：人工筛选门

候选主题可以重叠、不稳定、改名、合并、拆分或被拒绝 —— 这部分自动化能做
（见[统一主题池](unified-theme-pool.md)）。但**候选不能直接变成正式主题**。

人工筛选至少要回答：

- 它是不是一个**可持续研究的问题**，而不只是方法名、地区名或关键词？
- 纳入和排除边界能否说明？
- 哪些来源代表该主题，哪些只是相邻或歧义材料？
- 它与已有主题是父子、相邻、重叠、合并还是拆分关系？
- 当前证据是否足以建立，还是应该观察、补证据或拒绝？

人工决定可以是：建立 / 改名后建立 / 合并 / 拆分后重审 / 观察 / 补证据后再决定 / 拒绝。
只有**建立、改名后建立、合并**能产生正式主题，且必须记录**决定人、时间、理由与来源候选**。

## 正式主题

至少包含：核心研究问题、层级与边界、证据来源、Claim 准入、比较框架、当前综合、研究脉络、
异质性与争议、迁移边界、证据缺口、后续补证据任务。

**一级**主题 = 长期方向；**二级** = 相对稳定的问题群；**三级**只在材料规模和问题边界确有需要时建立。

**卡片与主题的关系独立保存**：新增文献主要增加或更新关系、补充主题综合，
**不因为主题变化而反复重写证据卡**。主题合并 / 拆分 / 改名 / 归档保留历史身份与前后关系，
**不能直接覆盖**旧主题。

证据不足时产生三类反馈：重新核对某个来源 / 补充缺失语料 / 修正发现模型。
反馈必须指向受影响的卡片、Claim 或发现阶段，说明**最小补查材料与停止条件**；
完成后再重算受影响的主题部分。

## idea 候选

只能从**正式主题 + 已核验 Claim + 明确缺口**形成。每个候选要说明：研究问题或假设、证据基础、
缺口为何存在、研究对象、可用数据、拟用方法、可证伪结果、可行性、潜在贡献、不确定性与风险。

时效、标准化引用、期刊位置和主题增长可以帮助决定**先评估哪个**，但**不能提高证据质量**，
也不能把当前语料中的空白自动宣称为创新。idea 是否成立由**研究者和导师**判断。

## 工具分工：Codex 与 Obsidian

Codex 负责接受自然语言任务、搜索材料、组织证据、生成候选，并**提出需要人判断的问题**；
Obsidian 负责让研究者阅读卡片、沿链接浏览主题、比较修改与完成审核。

**正式接入尚未实现。** 目标方案：文件型 MCP 作为 Vault 的后台接口（第一阶段只读）；
Obsidian 官方 CLI 负责打开结果、查看差异；Local REST API 只在需要当前活动笔记时使用。
后续受控写入**仅允许指定草稿或协作目录**，并要求冲突检测，**默认禁止删除、移动和批量改名**。

## 完成边界

这条线的完成判据**不是**「生成了若干 Markdown」，而是：

来源可追溯；自动粗卡与已核验证据卡**可区分**；候选主题**不能绕过人工门**；
正式主题能**回链 Claim 并保留演化历史**；Obsidian 修改**不会被后台覆盖**；
idea 候选能说明证据基础、可检验性与不确定性。
