# 输出与导出

一次运行会在 `--output-dir` 下写六个文件（`--dry-run` 不写；启用 `--web-search` 时另加 `web_candidates.csv`）。

## `form_summary.csv`（表格导出，可选）

这是给学院/机构表格用的导出格式，不是唯一输出；做研究方向对照时主要看
`works.csv` / `works_by_person.md`。表头按常见自查表列名：

```text
序号,所属研究所,姓名,2021年以来本人发表的论文数量,其中本人作为第一通讯作者的论文数量（如论文无通讯作者，则以第一作者计算）,自查是否存在问题,如自查涉及问题请补充
```

- 身份已确认：数量列写整数（0 也写 0）。
- 身份有歧义/未找到/查询失败：数量列**留空**，最后一列写「待人工确认：原因」。绝不写 0 冒充。
- 「自查是否存在问题」取自名单的 `自查结论`；未填则留空。
- 文件是 UTF-8 BOM，Excel 直接打开不乱码。

## `summary_audit.csv`

在前七列基础上追加：

`OpenAlexID, ORCID, 匹配状态, 撤稿数, 不含撤稿论文数, 数据来源, 复核标记`

用于内部复核，不建议直接上交。

## `works.csv`

每篇论文一行，字段包括：

- 基本信息：标题、年份、发表日期、类型、期刊/会议、DOI、WorkID、OpenAlex URL
- 作者信息：**本人署名、作者序号/作者总数、完整作者列表**、作者位次
- 判定信息：是否第一作者、是否通讯作者、**是否计入**、**计数原因**（第一作者/通讯作者/第一+通讯/未计入）
- 复核信息：是否撤稿、本人单位、单位匹配、复核标记、合并的重复条目、数据来源

布尔值用 `是/否`。这一页是**审计线索**：汇总里的每个数字都能在这里找到对应论文，
也能看到哪些论文**没有**计入、为什么没有计入。

## `works_by_person.md`

按人分组的可读清单，适合直接打开逐篇校核：

- 每人先列身份、OpenAlex ID、汇总数字；
- 然后列出**全部**检索到的论文（包括未计入的），表格含本人署名、作者序号/总数、位次、第一/通讯、是否计入、计数原因、撤稿、DOI、复核标记；
- 每人末尾有一行**对账**：「清单 N 篇，计入 M 篇，与汇总一致」；不一致时会用 ⚠ 标出。

如果学院/机构或个人对某个数字有疑问，先看这份清单的「计入」「计数原因」「复核标记」三列。

## `summary.json`

机器可读版本，包含 `config`、`totals`、每个人的 `query/identity/stats/works/review_flags/status/error`。
不会写 API key。

## `review.md`

人工复核清单：

- 同名候选（需要你选）
- 通讯作者信息缺失（非第一作者，未计入）
- 撤稿论文
- 作者列表截断
- 单位不匹配
- 预印本未见刊
- 查询失败/额度耗尽

## `web_candidates.csv`（仅 `--web-search`）

中文库网页检索的候选：`姓名,标题,作者,来源,年份,URL,置信度,状态`。
默认 `confidence=low`、`status=pending`，**不参与统计**。

provider 由 `--web-search none|deepseek|firecrawl` 决定：`deepseek` 复用
`DEEPSEEK_API_KEY`（推荐国内用户），`firecrawl` 需要 `FIRECRAWL_API_KEY`。
不启用网页检索时不会生成这个文件。

确认流程：

1. 看 `web_candidates.csv`，把确认的论文整理成 `confirmed.csv`（列见下）。
2. 重跑时加 `--supplement confirmed.csv`。

`confirmed.csv` 最少需要：

```csv
姓名,标题,年份
张三,某中文论文,2023
```

可选列：`期刊,DOI,作者位次,是否通讯,类型,作者,本人署名`。作者位次用 `first/middle/last`；
`作者` 列用 `|` 分隔完整作者名单，工具会据此自动算出「作者序号/总数」；
`本人署名` 用于英文论文或姓名变体（如 `Zhang San`），工具用它定位作者序号。
没有位次和通讯标记时不计入第一通讯，并在 `works.csv` 标记 `supplement_position_missing`。

中文论文建议逐篇核对后再放进 `confirmed.csv`。知网/万方没有稳定公开 API；用它们的
公开检索页找到题名即可，不需要在工具里登录知网。

!!! note "在线首发早于 2021、见刊在 2021"
    OpenAlex 用在线首发日期过滤。像 *Environmental Research Letters* 2021, 16(2): 024025
    这篇，OpenAlex 记的是 2020-12-18，会被 `2021-01-01` 挡掉。把 `年份` 填成见刊年
    （2021）写进 `confirmed.csv`，再用 `--supplement` 补一条即可。

## 怎么导出成学院/机构表格

1. 打开 `form_summary.csv`。
2. 把「自查是否存在问题」逐人改成「无」或具体问题；程序不会替你写「无」。
3. 需要补充说明的写最后一列。
4. 复制到学院/机构下发的 Excel/Word 表即可。
