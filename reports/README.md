# 老师进度摘要

[daily/](daily/README.md) 按日期保存“新增、完成、等待与阻塞”的 Markdown 摘要及配套 JSON。

run-once 在监控路径中刷新摘要；daily-report 可单独刷新，两者的摘要生成不额外调用 AI。本机每日计划已经部署，由同一 run-once 产生日报；报告文件存在本身不证明计划正在正常运行，需查看 schedule-status。

报告来自本机已观察的共享库、任务、成果和关键事件，不等于云端最新全量状态。贡献者字段缺失时如实记录未知，不根据论文作者或用户名猜学生身份，不用于排名。

日报属于可共享成果，提交/推送仍须用户明确要求；不通过微信或邮件自动发送。
