# 原文忠实性与科学边界

## 四层表述

1. **来源事实：** 来源直接报告的设计、观测、数值、条款或实现。
2. **来源解释：** 作者或发布方对事实的解释、贡献声称、政策理由或建议。
3. **忠实归纳：** 为当前问题重组来源信息，但不增加来源没有的因果、范围、方向或确定性。
4. **本方判断：** 比较、推断、风险或使用建议；必须与前三层分开，并公开依据和不确定性。

不得把第 2—4 层写成第 1 层。

## 声明的最小可核单元

每个 Cxx 只表达一个可检查命题。至少保留：对象、地点、时期、尺度、研究或统计单位、条件、比较对象、方向、数值、单位、分母、不确定性和语气限定。来源没有的要素不补造。

位置使用可重复定位的组合：来源版本＋印刷页/PDF页序＋节标题＋图表/条款/附录。网页使用标题、章节或段落锚点、版本和访问日；代码使用 release/commit＋文件＋行或函数；数据使用版本＋变量/字段/记录。

## 阅读范围状态

- metadata：只核了题录。
- abstract：读到摘要，没有核正文。
- partial_full_text：读到指定章节、页或图表。
- full_text：主文全部读过；附件另记。
- supplement：读到列明的补充材料，主文范围另记。
- data_sample／full_data：分别检查了样例或完整数据范围。
- source_code：检查到固定版本源代码。
- actual_run：实际执行了固定输入、配置和环境。
- mixed：上述多种材料的组合，必须在正文逐项列出。

不得由“附件存在”推成“全文已读”，也不得由全文索引存在推成页码和公式均已核。

## 缺失和否定表达

结构字段只使用统一 missing_status：

- not_applicable：确实不适用，并在相邻说明中给原因。
- not_obtained：材料不可访问或未提供。
- not_read：材料已经取得，但本轮没有读。
- not_reported：已经检查列明范围，来源没有报告。
- not_found_after_check：已经按列明路径检索，仍未找到目标信息。
- conflict_pending：两个位置或版本不一致，尚未解决。

扫描、图像或 OCR 无法可靠辨认时使用 not_found_after_check，并在说明中写明无法辨认的对象和检查范围。

“没找到”不等于“作者没做”；“未报告”不等于“没有”；“无显著差异”不等于“等效”。

## 水利研究常见越界

- 历史强迫下模拟不写成实时预报；未来情景不写成已发生事实。
- 多流域训练不自动等于跨流域泛化；网格或时序点不自动等于独立样本。
- 校准、调参、选模、验证和最终测试必须按实际用途区分。
- NSE、KGE、RMSE 等指标记录实际公式、聚合方式、样本范围和方向；不同变体不混用。
- 特征重要性、敏感性、相关关系不写成因果机制。
- 模拟收益、设计预期、验收通过和长期实测效果分别记录。
- 政府或权威来源仍需核对统计口径、样本、版本和不确定性。
- 标准要求只证明规范边界，不证明方法科学性能最优。
- 代码可下载、安装成功、测试通过、输出生成和复现论文结果是不同状态。
- 数据产品说明中的精度不自动等于目标流域上的实际精度。

## 二次来源和独立性

综述、教材、政策、报告引用原研究时写“该来源转述”。未打开原始研究，不得把引用挂到原始研究名下当作已核。多篇综述引用同一研究、同一数据集或重叠样本时，不能计为多次独立证实。

## 引文与版权

只保存核对所需的短引文和忠实释义。共享 Git 仓库不保存受版权保护的 PDF、大段原文、Zotero 数据库、访问凭据或临时全文包。全文继续由 Zotero 或有授权的文件系统管理。
